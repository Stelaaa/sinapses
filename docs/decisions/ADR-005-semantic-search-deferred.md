# ADR-005 — Busca semântica adiada

## Status

Aceito

## Contexto

Embeddings e bancos vetoriais aumentariam a complexidade inicial do MVP.

## Decisão

O MVP utilizará inicialmente recuperação textual simples.

Embeddings, busca semântica e recuperação híbrida serão avaliados após a validação do fluxo principal.

## Consequências

### Positivas

- menor complexidade inicial;
- menor número de dependências;
- desenvolvimento mais rápido.

### Negativas

- menor capacidade de recuperação semântica.
