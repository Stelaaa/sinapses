# ADR-003 — Markdown como fonte inicial de conhecimento

## Status

Aceito

## Contexto

O MVP precisa de uma fonte simples, portátil e fácil de versionar para conhecimento documental.

## Decisão

Markdown será utilizado como fonte inicial de conhecimento.

A recuperação será baseada inicialmente em índice e busca textual.

## Consequências

### Positivas

- simplicidade;
- portabilidade;
- facilidade de edição;
- facilidade para criação de exemplos e testes.

### Negativas

- recuperação limitada em comparação com busca semântica;
- pode exigir evolução futura para embeddings e recuperação híbrida.
